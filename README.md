# «Ремонт окон ПВХ» — лендинг ремонта окон (Симферополь и Крым)

Одностраничный сайт под трафик из Яндекс Директа. Цель — заявка на бесплатную диагностику.
Статика (HTML/CSS/JS) + обработчик заявок `send.php` (PHP 7.4+).

## Структура

| Файл | Что это |
|---|---|
| `index.html` | Лендинг |
| `spasibo.html` | Страница после отправки заявки (цель Метрики по URL) |
| `politika.html`, `soglasie.html` | Политика и согласие (152-ФЗ) |
| `css/style.css`, `js/main.js` | Стили и скрипты |
| `send.php` + `config.php` | Приём заявок: почта, Telegram (необязательно), журнал `data/leads.csv` |
| `img/` | Стоковые фото Unsplash (лицензия Unsplash, атрибуция не обязательна) — **временные**, заменить на реальные фото работ |

## Перед запуском

1. **Почта для заявок** — `config.php` → `to_email`; `from_email` — ящик на домене сайта.
2. **Домен** — заменить `DOMAIN` в `index.html` (canonical, JSON-LD), `robots.txt`, `sitemap.xml`, `config.php`.
3. **Яндекс Метрика** — номер счётчика в `js/main.js` → `METRIKA_ID`.
   Цели (JavaScript-событие): `lead` (любая заявка), `form_send`, `quiz_done`, `phone_click`, `form_start`, `quiz_start`, `quiz_contacts`, `modal_open`.
   Плюс цель «посещение страниц» — `spasibo.html`.
4. **Реквизиты** — ИП/ООО, ИНН, ОГРН(ИП), e-mail в `politika.html`, `soglasie.html` (жёлтые поля) и в подвале `index.html` (комментарий `ЗАПОЛНИТЬ`). Их требует модерация Директа.
5. **Подтвердить у заказчика** (помечено `ПОДТВЕРДИТЬ` в коде): цены «от», условия выезда по Крыму, обслуживание «под зиму» от 900 ₽.
6. Отзывы — блок закомментирован в `index.html`; включать только с реальными отзывами.

## Хостинг

- Обычный хостинг с PHP (Beget, Timeweb и т.п.): залить всё как есть. `mail()` должен быть включён; для надёжности можно дублировать заявки в Telegram (`config.php`).
- Yandex Object Storage (статический хостинг) PHP не выполняет — нужна Cloud Function, адрес которой ставится в `FORM_ENDPOINT` в `js/main.js`.

## Заявка в письме

Телефон, имя, проблема / ответы квиза, форма-источник, UTM-метки (`utm_source`, `utm_campaign`, `utm_term`…), `yclid`, страница входа, реферер, IP.
Антиспам: скрытое поле-ловушка + отсечка ботов, отправивших форму быстрее 2 секунд.
